# 🎙️ Game Voice Studio

Make **free** expressive AI voices for your game, change them to **robot / ghost / kid / man / woman / monster / alien** and more, then download **MP3** files.

Perfect for funny conversations between two characters (like a taxi driver and a scared passenger 😄).

## How to use (3 minutes)

1. **Open the app** — just open `index.html` in Chrome (double-click it, no install needed).
2. **Get a free Google API key** (one time only):
   - Go to https://aistudio.google.com/apikey
   - Press **Create API key** and copy it
   - Paste it in the app — it is free, no credit card needed
3. **Write your conversation** (or press 🎬 *Load funny taxi sample*):
   - Pick a base AI voice for each character (men, women, deep, upbeat...)
   - Pick a fun effect: 🤖 Robot, 👻 Ghost, 🧒 Kid, 🐿️ Chipmunk, 👹 Monster, 👽 Alien, 📻 Radio...
   - Add emotions inside the text: `(laughing) No way!`, `(screaming) STOP!`, `(whispering) it's behind you...`
4. Press **🎙️ Generate all voices**, listen with ▶️, then **⬇️ Download MP3**.

You can also download each line as its own MP3 to use separately in your game.

## Notes

- Works with **English and Arabic** text.
- The voice effects run on your device, so they cost nothing.
- If the MP3 encoder can't load (no internet), you get a WAV file instead — game engines accept WAV too.
- Free plan limits: if you see a "quota" error, wait a minute and try again.
